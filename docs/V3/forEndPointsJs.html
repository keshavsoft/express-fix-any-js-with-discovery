Step 2 - Endpoint Generation Documentation

Overview

This module automatically generates Express endpoint methods based on the selected schema. It reads the schema configuration, generates controller imports, and creates the required HTTP methods.

Step 2 - Generate Endpoint Methods

File

test/v15/forEndPointsJs/end-points.js

Purpose

  • Generates endpoint methods based on the selected schema.
  • Creates controller imports automatically.
  • Reads schema, table path and configuration.
  • Generates Express endpoint methods.

Generated Endpoints

router.get("/find/:ledgerName", ...);

router.get("/showAll", ...);

Depending on the selected options, the generator can create:

  • GET
  • POST
  • PUT
  • DELETE

Workflow

Read Schema
↓
Generate Controller Imports
↓
Create Endpoint Methods
↓
Generate GET / POST / PUT / DELETE
↓
Ready-to-Use Express APIs
